Planetary Motion

A math-based animation using angles, sine, cosine, and circular motion.

Controls
SPACE = pause / resume   |   UP ARROW = increase speed
DOWN ARROW = decrease speed

The planet's position is calculated with x = centerX + radius × cos(angle) and y = centerY + radius × sin(angle). The angle changes every frame, so the planet continuously moves around the sun.
